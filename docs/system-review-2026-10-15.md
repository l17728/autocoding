# 2026-10-15 系统代码审查与剩余工作

后续 P2 实现及新增验证见 [P2 实现与验收记录](p2-delivery-2026-10-15.md)。下表保留初始审查的发现和验收条件，不表示这些功能仍全部未实现；完整原生交互与真实模型效果评测仍未关闭。

## 审查方式与统一结论

本轮由三个独立审查代理分别检查功能正确性、性能与可靠性、界面易用性；主代理检查执行与验收边界，并进行交叉复核和集成验证。这里的“专家”指带不同职责的审查代理，不是外部真人认证。

审查一致采用以下判断：状态推进由代码控制，完成结论必须绑定当前任务版本和真实验证证据；未知执行结果保持待对账；历史知识不能扩大授权；页面不能把过时响应或历史报告呈现为当前状态。修复范围包括直接缺陷及同类调用路径，不将测试通过扩大为全部生产门禁通过。

产品仍为本地多项目、单 Owner 的 0.2.0 开发版。已有可运行的托管开发、问答审批、独立验证、知识自检和收尾查询。本轮修复后仍有生产发布阻断项，尤其是 Owner 对账恢复闭环和最新流程的真实供应商验收。

| 可靠性 P1 | 单个超大事件被裁掉后复盘游标永久停滞 | 保留事件 ID 并明确标记内容截断，原始证据仍在账本；大事件推进测试 |
| 一致性 P1 | 并发刷新可重复输出、旧快照覆盖新快照、A→B→A 切换错配响应 | 请求代次隔离与输出游标去重，延迟响应浏览器回归 |
| 性能 P2 | 复盘及回答历史检索同步阻塞事件循环 | 移至工作线程，包括 Host 的知识读取；用心跳测试验证事件循环可继续推进 |
| 性能 P2 | 每次回答重建全部权限历史，并保留大量相似项 | 流式读取有效用户答案，只保留最优 5 条；不扫描权限历史回归 |
| 性能 P2 | 收尾失败记录逐条扫描全部运行，持写锁时 O(n²) | 按任务预聚合最新通过时间，关联改为 O(n) |
| 可靠性 P2 | 最新 50 条之外的 running 自检重启后残留 | 独立扫描恢复全部 running 复盘，历史窗口外恢复测试 |
| 知识质量 P2 | 同一收尾原则因次数变化不断形成冲突 | 统计数字留在来源报告，通用原则使用稳定正文并合并来源 |

| 可用性 P2 | 终端断线后仍可输入，单会话没有重连入口 | 断线冻结输入并清空未发送队列；支持仅重连输出、不重发命令 |
