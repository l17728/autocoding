# 故障、原生交互与学习评测补验

本轮只执行已授权的非智谱工作。长期真实业务负载继续搁置；原生菜单探针不发送模型提示，不登录 Claude，不触发 OpenCode 模型请求。

## 故障边界

新增真实本地子进程测试：stdout 队列堵塞时重复关闭；取消事件等待后，在 RPC 通知堵塞时关闭并清理待处理请求；进程断开后同时到达的批准/拒绝均不得发送。持续堵塞冻结、并发审批只发送一次、未知投递不重发由已有测试覆盖。

首次传输专项 24 项有 1 项失败：原有 UTF-8 分帧测试等待 3 秒超时，三个新增边界用例均通过。日志 `.local/fault-boundaries.log`。未放宽该测试的断言或超时，最终回归另记录。

## 原生交互

`AUTOCODING_NATIVE_INTERACTIONS=1` 启用本地交互验收：Codex 斜杠菜单、OpenCode 命令面板导航/退出、Claude 主题选择到认证页面，以及人工接管。完整命令/文件审批、自定义问题回答和模型上下文仍须各自实测，局部成功不能标记完整矩阵通过。

Codex 首轮菜单确已显示，但用例错误要求可见 `/help`；根据实际首屏 `/permissions` 修正断言。Claude 主题选择后的实际页面为 `Security notes`，旧用例错误要求直接出现登录页，已按实际引导修正。运行中的重试使用已加载的旧断言，这些失败记录保留，不归为产品菜单失败。

第一轮 OpenCode 报告曾记录本地菜单与接管通过（`.local/native-browser-opencode-1792140112817/report.json`），模型提示 0。后续发现旧的大小写不敏感 `commands` 断言也会命中普通页面的底部快捷键提示，故**撤销该报告的命令面板通过结论**，保留原始报告供追溯。修正菜单断言后的第二轮 Claude 首次通过、Codex 第三次通过，汇总 `1 passed / 1 flaky`（`.local/native-local-interactions-corrected.log`）。Codex 前两次因接管成功提示被连接关闭提示覆盖而失败；最终用例改为验证接管 HTTP 200、owner=human、epoch 增加 1、state=reconciling 和恢复入口可用，检查真实状态而非瞬时提示。

整套浏览器含原生交互结果：**18 项通过、1 项跳过、1 项失败，17.7 分钟**（`.local/final-browser-interactions.log`）。Codex、Claude 最终版均首次通过；OpenCode 三次未完成启动验收，包含两次整体 150 秒超时和一次未见启动界面，状态仍为等待启动界面，不能归因于 Ctrl+P 或智谱额度。按三次上限停止本轮原生复验。

收尾时仅补强探针诊断：时序起点包含隔离仓库准备，页面快照读取最多等待 2 秒，读取失败仍保存已采集事件，不因此丢失整份诊断。该诊断增量未再次启动原生供应商用例，不计作新的原生验收证据。

代码检查另发现前端拒绝 Ctrl+P，后端也无按键映射；已增加固定命名键 `ctrl_p`，普通模式发送 `0x10`，Win32 模式发送对应 P+Ctrl 键事件，不放开任意控制序列。真实 ConPTY 单项测试 **通过，10.737 秒**（`.local/ctrl-p-conpty.log`），验证两种模式收到 `0x10` 及重复请求不重发。浏览器增加物理 Ctrl+P 只发送一次命名按键的回归；OpenCode 断言改为大小写敏感的面板标题并要求 Escape 后消失。该按键修复不等于原生启动问题已解决。

## 评测数据隔离

新增离线工具 `tools/prepare_history_holdout.py`。以冻结的冷启动语料为排除集，按来源文件/会话、规范化文本、包含关系和重复记录排除泄漏；仅导出来源 ID、文本摘要和审核状态，不导出历史原文、不调用模型、不写入知识库。文件摘要用于追溯排除集，输出不得覆盖输入。

现有 1,487 条私有历史指令全部来自冷启动使用过的语料，因此本次审计排除 1,487 条，独立保留样本为 **0**；报告 `.local/evaluation/holdout-audit.json`。不能从同一批已见历史中追认独立未见样本。未来新来源仍需核对完整上下文、真实用户答案和语义近似，工具不会自动认证其独立性或推断标签。

复跑命令：

```powershell
.\.venv\Scripts\python.exe tools/prepare_history_holdout.py --input .local/cold-start/user-instructions.jsonl --exposed .local/cold-start/user-instructions.jsonl --output .local/evaluation/holdout-audit.json
```

合成评测候选从 12 项扩展到 **16 项（9 个范围内、7 个范围外）**：补充部分任务搁置、旧收益出现退化、跨项目误用授权、改名案例冒充保留集。文件 `docs/evaluation-candidates.json` 仍是合成草稿，没有作为真实独立样本或自动导入知识库。

16 项已在临时 Host 中通过实际 `save_suite` 接口校验，模型调用 0。泄漏审计的来源隔离、格式变换、文本包含关系、重复和不自动认证等行为测试 2 项通过（`.local/holdout-tests.log`）。
