# 开发智能体协作平台设计基线

版本：1.0 定稿基线（独立专家复核通过，可启动 M1）。范围：Windows 本地开发协作，支持 Codex、OpenCode、Claude Code；不支持游戏。本文档集整合根目录两份原始 DOCX，并以本次用户补充的“可视交互、三种 Agent、智谱接入、审阅后开发”为最高需求依据。

原始 DOCX 保留不改。新需求与旧文档冲突时，按下列已确定决策执行：去除 EU4；首个产品版本包含可视工作区；PM 可在既定约束内裁定技术争议；PM 只改平台知识记录，业务文件交给执行 Agent；底层对象有固定契约，知识内容允许扩展；“自主不中断”表示持续调度和恢复，不表示无限重试或越权操作。

## 证据与版本

调研时间以本次环境日期 2026-10-12 为准。本地 CLI：Codex 0.162.1、OpenCode 1.19.0。联网与部分本机配置路径受执行环境限制；未经验证的 Claude/智谱配置不作为已通过集成验收的功能。每次更换 CLI 版本必须重新执行能力探测与契约测试。

需求、用例、事件、开发任务分别使用 FR/NFR、UC、EV、DEV 编号。设计基线与实现完成度分别记录，不以设计定稿表示产品已实现。
