## 超长与折叠输入

旧实现虽然能一次性写入 UTF-8 外部草稿，仍要求屏幕完整显示正文。超过可见编辑区域或被折叠时，会停止而不提交。

现改为两阶段交接：

1. 通过 Codex 外部编辑器写入一次正文，保留已有非空草稿拒绝覆盖的规则。
2. 重新打开外部编辑器，读取 Codex 从当前输入框导出的新草稿；逐字节核对完整 UTF-8 内容和 SHA-256，不修补、不重写不一致的文本。
3. 父进程仅接受对应请求 ID、摘要和 `verify` 阶段回执。网页再次核对原始输入摘要，并持续检查会话 ID、代次、所有权、暂停及存活状态，等待 500 毫秒后单独发送一次 Enter。

因此，无须根据屏幕折叠占位符猜测隐藏正文。短文本仍保留屏幕完整回显确认路径。读回成功只确认待提交草稿，不代表模型执行完成或项目验收通过。

每阶段最多等待 60 秒、最多尝试打开本地编辑器三次，仅在对应请求未被消费时重开；不会重复写入正文或自动追加 Enter。读回摘要错误、丢失回执或超时沿用冻结/停止流程。平台私有交接目录随终端关闭清理，不修改全局配置。

保留现有单次 API 输入上限 65,536 字符；本次解决显示区域限制，不承诺超出接口上限或供应商上下文容量的输入。幂等重放不再次写入，也不返回可用于再次自动提交的读回证明。

官方 [CLI customization](https://learn.chatgpt.com/docs/cli-customization) 描述 Ctrl+G 打开 VISUAL/EDITOR，并在编辑器退出后将内容返回输入框；本项目额外增加上述读回验证。
